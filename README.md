# FocusHaven

> A little space for big ideas.

FocusHaven is an immersive, customizable 3D productivity workspace designed to help students, developers, and professionals stay focused while enjoying a calm and personalized virtual environment.

The project combines the Pomodoro technique, ambient soundscapes, personal organization, and productivity analytics within a cohesive interactive 3D experience.

## Project Status

Currently in development.

## Planned Features

### Focus Timer
- Interactive 3D Pomodoro timer
- Customizable focus and break durations
- Automatic session transitions
- Session logging and progress tracking
- Customizable timer appearance

### Ambient Audio
- Multiple ambient soundscapes
- Independent volume controls
- Custom audio presets
- Web Audio API integration

### Interactive 3D Workspace
- Fully rendered 3D environment
- Customizable furniture and room materials
- Adjustable lighting and time of day
- Interactive room objects
- Weather customization
- Saved room presets

### Notes and Task Management
- Personal notes with automatic saving
- Markdown and code snippet support
- Task organization and prioritization
- Task-linked focus sessions

### Productivity Insights
- Daily and weekly focus statistics
- Session history
- Focus activity heatmap
- Subject and project tracking
- CSV data export

## Design Philosophy

FocusHaven follows a cozy yet professional design approach, combining soft 3D geometry, pastel yellow and warm brown tones, subtle animations, and immersive spatial design.

The interface is designed as a continuous virtual environment rather than a conventional productivity dashboard.

## Privacy

FocusHaven is designed as a local-first application. Personal notes, tasks, session history, and customization preferences are intended to be stored locally in the user's browser.
